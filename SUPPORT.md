# V2UI support

Use [GitHub Issues](https://github.com/xuyang0921/V2UI/issues) for reproducible product problems and documentation questions.

Include:

- the V2UI version;
- the review surface: Chrome or Codex built-in browser;
- operating system, browser, and Node.js version;
- exact reproduction steps;
- expected and actual behavior; and
- sanitized error messages or logs.

Do not upload recordings, review manifests, access tokens, private project source, or any `.codex/` content. Use the private process in [SECURITY.md](./SECURITY.md) for vulnerabilities rather than opening a public issue.
