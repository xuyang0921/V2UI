# V2UI

<p align="right"><a href="../">English</a> | <strong>中文</strong></p>

V2UI 是面向 Codex 生成网站的本地预览评审层。它把语音、红色画笔和 DOM 选择关联为结构化反馈，并要求在任何代码修改前先说明源码影响范围、取得明确批准。

- [隐私政策](./privacy/)
- [使用条款](./terms/)
- [支持](./support/)
- [源码与发布包](https://github.com/xuyang0921/V2UI/blob/main/README.zh-CN.md)

当前公开 Beta：**0.4.1**。V2UI 只处理通过 `localhost` 或 `127.0.0.1` 提供的预览。
