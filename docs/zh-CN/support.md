# V2UI 支持

<p align="right"><a href="../../support/">English</a> | <strong>中文</strong></p>

对于可复现的产品问题和文档问题，请使用 [GitHub Issues](https://github.com/xuyang0921/V2UI/issues)。

请提供 V2UI 版本、Chrome 或 Codex 评审表面、操作系统、浏览器与 Node.js 版本、复现步骤、预期行为、实际行为和已脱敏的错误输出。

请勿上传录音、评审 manifest、访问令牌、私有源码或 `.codex/` 内容。漏洞请通过 [GitHub Security Advisories](https://github.com/xuyang0921/V2UI/security/advisories/new) 私密报告。
