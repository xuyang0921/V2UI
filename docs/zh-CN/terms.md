# V2UI 使用条款

<p align="right"><a href="../../terms/">English</a> | <strong>中文</strong></p>

V2UI 的选择、转录、录音和源码范围建议可能不完整或不准确。保存反馈不等于授权修改代码。Codex 必须先说明可能影响并取得明确确认，才能开始编辑。在合并或发布之前，你有责任检查源码变更、构建、无障碍、安全和发布结果。

Beta 版本按“现状”提供，可能发生变化、中断或本地数据丢失。在适用法律允许的最大范围内，发布者不作任何保证，也不对因使用 Beta 版本而产生的间接、附带、特殊、后果性或惩罚性损害承担责任。

本条款不取代适用于 V2UI 源码的许可证，也不取代 Chrome、Codex、浏览器语音服务或其他第三方软件各自的条款与隐私政策。
