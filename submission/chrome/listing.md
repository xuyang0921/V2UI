# Chrome Web Store Listing — V2UI 0.4.0

Category: Developer Tools

Short description: Review local UI previews with linked voice, red drawing, and DOM selections for Codex.

Detailed description: V2UI adds an explicit review layer to localhost and 127.0.0.1 web previews. Start a review to record microphone evidence, select visible DOM targets, and draw red annotations. Suggestions are saved locally in the reviewed project and can be returned to a bound Codex task. V2UI does not modify code when feedback is sent; Codex must summarize scope and wait for confirmation.

Recommended initial visibility: Unlisted beta.
