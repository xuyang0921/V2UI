# Chrome Web Store listing — V2UI 0.4.1

Category: Developer Tools

Short description: Review local UI previews with voice, red drawing, and DOM selections for Codex.

Detailed description: V2UI adds an explicit review layer to websites running on localhost or 127.0.0.1. Browse the real preview, select visible DOM targets, draw red annotations, and describe changes by voice. Chrome displays interim and final speech results while recording; if live recognition is unavailable, local recording continues so Codex can transcribe it later. Reviews are saved only in the project being reviewed. Sending feedback does not authorize code changes: Codex must summarize possible source impact and wait for explicit confirmation.

Permissions: V2UI uses Manifest V3 with only `activeTab` and `scripting`. Host access is limited to local previews. Screen and microphone permissions are requested only after the user starts a review.

What's new in 0.4.1: English product UI and publication materials, live Chrome transcription, playable Codex audio after pause, reliable save-and-return handoff, and complete suggestion deletion that also removes linked visual evidence.

Recommended initial visibility: Unlisted beta.
